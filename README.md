# Практическая работа № 2 — вариант 13

Дисциплина: «Конфигурационное управление».

## Описание

Инструмент анализа зависимостей пакетов Alpine Linux APK.

Текущий этап: 4 — обратные зависимости.

Программа читает настоящий репозиторий Alpine или тестовый JSON,
строит граф прямых и транзитивных зависимостей и выводит его.

Обход выполняется алгоритмом BFS без рекурсии.
Поддерживаются циклы и исключение пакетов по подстроке имени.

Зависимости извлекаются самостоятельно.
Менеджеры пакетов и сторонние библиотеки для сбора данных не используются.

## Требования и сборка

- Python 3.10 или новее.
- Bash для запуска run.sh.
- Интернет только для настоящего репозитория.

Используется стандартная библиотека Python.
Отдельная сборка и установка Python-пакетов не требуются.

## Структура проекта

- main.py — запуск программы из корня проекта.

- .gitignore — исключения для служебных файлов.

## Настройки

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| --package | Начальный пакет анализа | Обязательный |
| --repository | URL репозитория или путь к тестовому JSON | Обязательный |
| --test | Читать локальный тестовый JSON | Выключен |
| --output | Путь к будущему изображению SVG | graph.svg |
| --filter | Исключать имена с указанной подстрокой | Пустая строка |
| --reverse | Искать обратные зависимости | Выключен |

В настоящем режиме --repository принимает URL каталога
или полный URL APKINDEX.tar.gz.

В тестовом режиме файл должен существовать.
Имена тестовых пакетов состоят из больших латинских букв.

Фильтр учитывает регистр. Пустой фильтр отключён.
Фильтр не должен исключать начальный пакет.
Исключённые вершины не посещаются.
Узлы, доступные только через них, также не попадают в результат.
Если есть другой разрешённый путь, узел остаётся.

Параметр --output проверяется, но изображение пока не создаётся.
Расширение должно быть .svg, родительская папка должна существовать.

## Функции

### src/main.py

- build_parser() — описывает параметры и справку.
- validate_package() — проверяет имя пакета.
- validate_repository() — проверяет URL или наличие файла.
- validate_output() — проверяет путь результата.
- validate_filter() — проверяет фильтр.
- arguments(argv=None) — читает и проверяет параметры.
- main(argv=None) — выбирает источник графа и запускает анализ.

При argv=None параметры берутся из командной строки.
В тестах можно передать список параметров непосредственно.

### src/repository.py

- parse_index(text) — разбирает записи APKINDEX.
- unpack_index(data) — читает архив в памяти.
- load_repository(address) — скачивает индекс с таймаутом 30 секунд.
- direct_dependencies(packages, name) — возвращает требования поля D.
- dependency_name(requirement) — отделяет ограничение версии от имени.
- build_providers(packages) — создаёт карту поставщиков.
- resolve_dependency(requirement, packages, providers) — ищет пакет.
- repository_graph(packages) — строит граф пакетов репозитория.

Поля индекса: P — имя, V — версия, D — требования,
p — дополнительные имена, предоставляемые пакетом.

### src/graph.py

- load_test_graph(path) — читает и проверяет тестовый JSON.
- bfs(graph, start, excluded="") — обходит граф в ширину.
- reverse_graph(graph) — разворачивает рёбра всего графа.

BFS использует очередь deque и множество visited.
Вершина отмечается при добавлении в очередь.
Повторное посещение предотвращается, рёбра циклов сохраняются.

## Формат тестового репозитория

Ключ — имя пакета, значение — список его прямых зависимостей.
Каждая упомянутая зависимость должна быть объявлена ключом.

```json
{
  "A": ["B"],
  "B": ["C"],
  "C": []
}
```

Файлы JSON содержат данные графа.
Настройки программы передаются через командную строку.

## Примеры запуска

Справка:

```bash
bash run.sh --help
```

Цепочка:

```bash
bash run.sh --package A --repository tests/chain.json --test
```

Цикл:

```bash
bash run.sh --package A --repository tests/cycle.json --test
```

Одиночный пакет:

```bash
bash run.sh --package A --repository tests/isolated.json --test
```

Общая зависимость и фильтр:

```bash
bash run.sh \
  --package A \
  --repository tests/diamond.json \
  --test \
  --filter B
```

Настоящий репозиторий:

```bash
bash run.sh \
  --package xz \
  --repository https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64
```

Настоящий репозиторий с фильтром:

```bash
bash run.sh \
  --package xz \
  --repository https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64 \
  --filter musl
```

## Ограничения модели APK

Используется один индекс APKINDEX формата v2.
Формат Packages.adb не поддерживается.

Требования so: и другие дополнительные имена сопоставляются
с пакетами через поле p. Настоящее имя пакета имеет приоритет.

Если поставщик отсутствует или их несколько, зависимость
помечается как неразрешённая. При достижении такого узла
обход сообщает об ошибке. Несвязанные с корнем проблемы
в других частях репозитория анализу не мешают.

Ограничения версий сохраняются при чтении индекса, но их
совместимость не вычисляется. Это граф объявленных зависимостей,
а не полноценный решатель установки apk.

Конфликты с префиксом ! не становятся рёбрами зависимостей.
Несколько требований к одному пакету дают одно ребро.

## Коды завершения

- 0 — успешное выполнение.
- 1 — ошибка загрузки, данных или построения графа.
- 2 — неправильные параметры командной строки.

## Обратные зависимости

Переключатель --reverse включает поиск пакетов, которые зависят
от выбранного пакета непосредственно или транзитивно.

Сначала разворачиваются рёбра всего доступного графа,
затем применяется тот же BFS, что и для прямых зависимостей.
Начальный пакет не включается в итоговый список зависимых пакетов.

В этом режиме строки графа показывают обратные связи:
C -> B означает, что B требует C.

Для цепочки A -> B -> C обратные зависимости C — B и A.

```bash
bash run.sh --package C --repository tests/chain.json --test --reverse
```

Пример отсутствия обратных зависимостей:

```bash
bash run.sh --package A --repository tests/chain.json --test --reverse
```

Обратный обход с фильтром:

```bash
bash run.sh --package C --repository tests/chain.json --test --reverse --filter B
```

Обратный обход цикла:

```bash
bash run.sh --package A --repository tests/cycle.json --test --reverse
```

Фильтр применяется к развёрнутому графу и отсекает пути через
исключённые вершины. Циклы не вызывают повторного посещения вершин.

Для настоящего репозитория поиск ограничен выбранным индексом:
он не охватывает автоматически другие репозитории Alpine.
